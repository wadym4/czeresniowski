# Czereśniowski — мій бюджет

Проста програма для ведення особистого бюджету в злотих (PLN). Це один файл `index.html`, який працює прямо в браузері, без сервера та встановлення.

## Можливості

- Доходи й витрати з категорією, датою та коментарем
- Підсумки за місяць: доходи, витрати, залишок
- Кругова діаграма витрат за категоріями
- Стовпчиковий графік доходів і витрат за останні 6 місяців
- Два рахунки, особистий і бізнес, з фільтром по кожному
- Імпорт виписки з банку у форматі CSV (Bank Millennium, mBank, PKO BP, Revolut та інші): колонки визначаються автоматично, категорії підбираються за назвою магазину, повтори та перекази між власними рахунками пропускаються. Файл можна просто перетягнути на сторінку
- Експорт та імпорт усіх даних у JSON (резервна копія)

## Як користуватися

Відкрийте `index.html` у браузері. Дані зберігаються в самому браузері, тому час від часу робіть «Експорт JSON», щоб мати резервну копію.

## Встановлення на VPS

На сервері з Ubuntu або Debian, у папці репозиторію:

```bash
sudo bash deploy/setup.sh            # адреса <ip>.sslip.io з HTTPS
sudo bash deploy/setup.sh my.domain  # власний домен з HTTPS
```

Скрипт встановлює nginx, сервер даних (`server/server.py`, лише стандартний Python) і сертифікат HTTPS. Під час першого запуску він попросить придумати пароль для входу на сайт. Після входу дані зберігаються на сервері в `/var/lib/czeresniowski` і однакові на всіх пристроях. Щодня зберігається резервна копія, останні 60 днів.

Оновлення: `cd ~/czeresniowski && git pull && bash deploy/setup.sh`

Змінити пароль: `sudo -u czeres DATA_DIR=/var/lib/czeresniowski python3 /opt/czeresniowski/server.py --set-password`

## Автоматичне підтягування з банку

Працює через Enable Banking (PSD2), безкоштовний режим для власних рахунків.

1. Зареєструйтеся на enablebanking.com, створіть застосунок **Production** з Redirect URL `https://<адреса сайту>/api/bank/callback`, збережіть файл `.pem` і натисніть «Link accounts», щоб підключити свої рахунки.
2. Скопіюйте ключ на сервер: `scp ~/Downloads/<id>.pem root@<ip>:/root/eb.pem`
3. На сервері: `cd ~/czeresniowski && git pull && bash deploy/setup.sh && bash deploy/bank.sh <Application ID> /root/eb.pem`
4. На сайті натисніть «Підключити банк». Операції оновлюються автоматично раз на день, коли ви відкриваєте сайт, і за кнопкою «Оновити з банку».
