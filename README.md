# Czereśniowski — мій бюджет

Проста програма для ведення особистого бюджету в злотих (PLN). Це один файл `index.html`, який працює прямо в браузері, без сервера та встановлення.

## Можливості

- Доходи й витрати з категорією, датою та коментарем
- Підсумки за місяць: доходи, витрати, залишок
- Кругова діаграма витрат за категоріями
- Стовпчиковий графік доходів і витрат за останні 6 місяців
- Імпорт виписки з банку у форматі CSV (mBank, PKO BP, Revolut та інші): колонки визначаються автоматично, категорії підбираються за назвою магазину, повтори пропускаються
- Експорт та імпорт усіх даних у JSON (резервна копія)

## Як користуватися

Відкрийте `index.html` у браузері. Дані зберігаються в самому браузері, тому час від часу робіть «Експорт JSON», щоб мати резервну копію.
